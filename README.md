# Aldora Enterprise Suite Ultra

Enterprise manufacturing ERP dashboard built with HTML, CSS, JavaScript, TailwindCSS, and Chart.js.

## Features
- Executive Dashboard
- Finance & FP&A
- Production Management
- Quality Control
- Maintenance System
- Inventory Management
- Procurement System
- CRM & Sales Pipeline
- HR Management
- Risk Management
- Workflow Approval
- Strategic Projects
- Security & Audit Trail
- Board Reporting
- Dark / Light Mode
- CSV Export
- Print / PDF Support
- Responsive Enterprise UI

## Technology
- HTML5
- CSS3
- JavaScript
- TailwindCSS
- Chart.js
- Local Storage API
